# Contingencias de función

| Situación | Acción inmediata | Recuperación |
|---|---|---|
| El micrófono no abre | Mantener escena segura y usar overrides/blackout. | Revisar permiso y origen seguro; en operación de dos ventanas, pulsar **Iniciar micrófono** en la vista visual, no en el panel remoto. |
| El micrófono se desconecta o el audio se suspende | Congelar gestos erráticos. | Reconectar la fuente y pulsar **Iniciar micrófono**; la nueva sesión recalibra. |
| Calibración inestable | No confiar en onset/color. | Alejar el micrófono de parlantes, bajar realimentación y recalibrar durante 10 s. |
| FPS bajo | Pulsar **Modo seguro**; si hace falta, blackout. | Cerrar apps, comprobar proyector/resolución y volver a modo alto solo tras verificar estabilidad. |
| WEBGL perdido | Blackout para evitar una pantalla inconsistente; el panel sigue operativo. | Esperar la recompilación automática tras restore; si no vuelve `OK`, recargar solo la vista visual y comprobar el snapshot. |
| Panel separado desconectado | Operar con atajos en la vista visual. | Verificar que ambas ventanas usan el mismo origen/navegador, que `VISUAL` no diga `DUPLICADO`, y recargar el panel. |
| Navegador cerrado | Mantener blackout/proyector en negro. | Abrir la URL, verificar checklist, micrófono y calibración antes de continuar. |

No continuar un pasaje delicado con telemetría roja sin usar una de las redes de
seguridad disponibles.
